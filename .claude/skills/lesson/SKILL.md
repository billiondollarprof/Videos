# Turn a note into a rule

This is what makes the skills better with every video (the loop from Nate Herk's
editing playbook).

1. Write the note in `LESSONS.md` straight away: the date, his words (lightly tidied),
   the video it came from.
2. Decide where it belongs, and put it there in the same change:
   - a rule anyone should follow: `CLAUDE.md` section 5,
   - a step or a check: the skill's `SKILL.md`,
   - a number or a behaviour: the script, with a comment naming the date of the note.
3. Fix the video.
4. Tell him in one line: what changed in the video, and which rule or skill now holds it.
5. Commit with a message naming the note.
